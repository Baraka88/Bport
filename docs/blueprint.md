# **App Name**: ProFolio Studio

## Core Features:

- Dynamic Homepage Hero: A captivating homepage hero section featuring an auto-playing image slideshow and a typewriter effect to dynamically display introductory text about the user.
- Project Showcase: A dedicated section to display portfolio projects using interactive cards for technologies like Node.js, Vue.js, PHP, MySQL, and System Analysis. Each project will have its own detailed page with images, descriptions, and links to live demos or repositories.
- About Me Section: A personal bio section including professional experience, education, and a profile picture.
- Skills and Technologies: Interactive 'knowledge cards' and a clearly categorized list showcasing skills, programming languages, frameworks, and tools the user is proficient in, including Node.js, Vue.js, PHP, MySQL, and System Analysis.
- Certificates Showcase: A dedicated section to display professional certifications, achievements, and badges to highlight expertise and continuous learning.
- Enhanced Contact & Hire Me System: A robust contact and hiring inquiry system featuring client-side and server-side validation, email notifications to barakaruzibiza680@gmail.com upon submission, automated thank-you emails to users, and secure storage of requests in a MySQL database. Users can upload CVs/portfolios, select services, specify budget/timeline, and mark urgency. The system includes spam filtering, rate limiting, an admin panel to view/export requests to CSV, and redirects to a thank-you page post-submission.
- AI-Enhanced Project Descriptions: A tool that assists the portfolio owner in generating concise and impactful descriptions or taglines for projects based on provided technical details and goals.
- Dynamic Routing: Leverage Next.js dynamic routing to create unique URLs for each project, ensuring shareability and SEO friendliness.
- Enhanced Visitor Comments & Feedback: A system allowing visitors to leave comments and feedback on projects or the portfolio overall. Comments are stored in a MySQL database, validated for content and spam, and new comment notifications are sent to barakaruzibiza680@gmail.com. Comments are accessible for moderation and export by the portfolio owner.
- Theme Toggle (Dark/Light Mode): Enable users to switch between a dark and light theme for a personalized viewing experience, enhancing accessibility and aesthetics across all UI elements, including forms.
- Enhanced Collaboration Inquiry Feature: A comprehensive form for potential collaborators to express interest and outline project ideas, including options to specify project scope and estimated timelines. The system features form validation, file upload capabilities for project documents, email notifications to barakaruzibiza680@gmail.com upon submission, and auto-replies to collaborators. Inquiries are stored in a MySQL database. The page also includes a slideshow of images of developers and links to the owner's social media profiles (IG: barakajunior72, GitHub: baraka88, LinkedIn: baraka junior) to facilitate connection and context for potential collaborators.
- Visual Asset Gallery: A dedicated gallery section to showcase images, screenshots, and other visual assets related to projects or the portfolio owner's work, accessible from the main navigation.
- Secure Chat Access Control: Implement forms and authentication mechanisms to control access to a protected 'chatBRJ' feature, ensuring only authorized users can engage.

## Style Guidelines:

- Primary color: A sophisticated deep blue (#2E61BE) representing professionalism and trust. HSL(225, 65%, 45%)
- Background color: A very light, subtle blue-grey (#F1F6FB) for a clean and unobtrusive canvas. HSL(225, 15%, 96%)
- Accent color: A vibrant cyan (#2DCFE5) used sparingly for calls to action, highlights, and interactive elements. HSL(195, 80%, 55%)
- Headlines will use 'Space Grotesk' (sans-serif) for a modern, tech-inspired feel. Body text will use 'Inter' (sans-serif) for readability and a clean, professional aesthetic.
- Utilize minimalist line icons that are clean, contemporary, and align with the professional-tech aesthetic for navigation and feature representations.
- Employ a modular and responsive grid-based layout to ensure a consistent and clean presentation across all device sizes, prioritizing content clarity for both content and interactive forms.
- Subtle and elegant hover effects and page transitions, ensuring a smooth and premium user experience without being distracting.
